# Домашнее задание 7: Сравнение производительности различных подходов оптимизации

## Цель задания

Сравнить производительность различных подходов оптимизации инференса нейронных сетей:
- PyTorch (базовая версия)
- ONNX Runtime
- Torch-TensorRT

## Структура проекта

- `benchmark_resnet18.py` — основной скрипт для бенчмаркинга моделей (PyTorch, ONNX, Torch-TensorRT)
- `plot_benchmarks.py` — построение и сохранение графиков по результатам бенчмарка
- `benchmark_results.csv` — таблица с результатами всех запусков (используется для построения графиков и анализа)
- `save_resnet18_weights.py` — сохранение весов предобученной модели ResNet-18 в формате PyTorch
- `export_resnet18_onnx.py` — экспорт модели ResNet-18 в формат ONNX
- `optimize_resnet18_trt.py` — оптимизация модели с помощью Torch-TensorRT
- `weights/` — сохранённые веса моделей (PyTorch) (не хранится в git)
- `onnx/` — экспортированные ONNX-модели (не хранится в git)
- `trt/` — оптимизированные модели Torch-TensorRT (не хранится в git)
- `plots/` — все сгенерированные графики (PNG) 
- `REPORT.md` — подробный отчёт по эксперименту с анализом и графиками
- `README.md` — описание задания, структура проекта
