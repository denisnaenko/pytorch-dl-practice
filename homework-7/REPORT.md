# 1. Введение

**Описание задачи:**  
В рамках данного задания проведено сравнение производительности различных подходов оптимизации инференса сверточной нейронной сети ResNet-18 на различных размерах изображений и батчей. Сравнивались три варианта: базовый PyTorch, ONNX Runtime и Torch-TensorRT.

**Методы оптимизации:**  
- **PyTorch:** стандартный запуск модели на GPU.
- **ONNX Runtime:** экспорт модели в формат ONNX и запуск с помощью ONNX Runtime.
- **Torch-TensorRT:** оптимизация модели с помощью Torch-TensorRT для ускорения инференса на GPU.

**Ожидаемые результаты:**  
Ожидалось, что оптимизированные варианты (ONNX, TensorRT) покажут ускорение по сравнению с базовым PyTorch, особенно на больших батчах и изображениях, а также более эффективное использование ресурсов GPU.

---

# 2. Методология

**Экспериментальная установка:**  
- Операционная система: Ubuntu Linux
- GPU: NVIDIA GeForce RTX 3050 Ti Laptop GPU  
- Драйвер NVIDIA: 535.230.02
- CUDA: 12.2

**Параметры тестирования:**  
- Размеры изображений: 224x224, 256x256, 384x384, 512x512
- Размеры батча: 1, 2, 4, 8, 16, 32 (не для всех размеров из-за ограничений памяти)
- Для каждого варианта запускалось несколько прогонов, усреднялись результаты (отбрасывались 10% лучших и худших).

**Методы измерения:**  
- Время инференса (мс)
- FPS (кадров в секунду)
- Использование GPU и CPU памяти
- Ускорение относительно PyTorch

## Сравнительный анализ

- **PyTorch** показывает стабильную и высокую производительность на малых и средних батчах.
- **ONNX Runtime** уступает PyTorch на малых батчах, иногда значительно, но может быть полезен для кроссплатформенных решений.
- **Torch-TensorRT** показывает наилучшие результаты на малых и средних размерах батча, иногда превосходя PyTorch по FPS, но не всегда доступен для больших размеров из-за ограничений памяти.
- Для больших размеров изображений и батчей наблюдаются пропуски данных (OOM), что связано с ограничениями GPU.

# 4. Обсуждение

**Ответы на вопросы анализа:**

1. **Какой подход показывает лучшую производительность?**  
   - Torch-TensorRT показывает наилучший FPS на малых и средних батчах, иногда превосходя PyTorch. ONNX Runtime уступает обоим на большинстве конфигураций.

2. **Как размер изображения влияет на производительность?**  
   - С увеличением размера изображения FPS падает для всех подходов. Torch-TensorRT и PyTorch демонстрируют схожие тренды, ONNX — ниже.

3. **Как размер батча влияет на производительность?**  
   - FPS растёт с увеличением батча до определённого предела, после чего рост замедляется. Для больших батчей возможны ошибки OOM.

**Выводы о выборе оптимального подхода:**  
- Для максимальной производительности на GPU рекомендуется использовать Torch-TensorRT, если он поддерживается и нет ограничений по памяти.
- ONNX Runtime может быть полезен для кроссплатформенных решений, но на данном железе уступает по скорости.

# 5. Заключение

**Основные выводы:**  
- Оптимизация инференса даёт прирост производительности, но не всегда (зависит от железа и размера батча/изображения).
- Torch-TensorRT — лучший выбор для NVIDIA GPU, если нет ограничений по памяти.
- ONNX Runtime уступает по скорости, но может быть полезен для переносимости.
