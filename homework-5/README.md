## Описание utils.py

`utils.py` содержит вспомогательные функции, используемые во всех заданиях:
- `plot_and_save` — визуализация и сохранение изображений/графиков.
- `get_classes`, `get_images`, `get_sample_images` — выборка классов и изображений из папок.
- `ensure_results_dirs` — создание структуры папок для результатов.


## Описание заданий

**Задание 1: Стандартные аугментации torchvision**
- Применение стандартных аугментаций к изображениям из разных классов.
- Визуализация и сохранение результатов.

**Задание 2: Кастомные аугментации**
- Реализация и сравнение кастомных аугментаций с готовыми.
- Визуализация и сохранение результатов.

**Задание 3: Анализ датасета**
- Подсчет изображений по классам, анализ размеров, построение гистограмм и scatter plot.
- Сохранение статистики и графиков.

**Задание 4: Pipeline аугментаций**
- Класс AugmentationPipeline с методами добавления/удаления аугментаций.
- Несколько конфигураций (light, medium, heavy), применение и сохранение результатов.

**Задание 5: Эксперимент с размерами**
- Измерение времени и памяти при обработке изображений разных размеров.
- Визуализация зависимости времени и памяти от размера.

**Задание 6: Дообучение предобученной модели**
- Дообучение ResNet18 на своем датасете, замена последнего слоя.
- Визуализация процесса обучения (loss/accuracy), сохранение весов модели.

## Как воспроизвести
1. Запустите поочередно скрипты `task1_standard_augs.py`, ..., `task6_finetune_model.py`.
2. Все результаты и графики сохраняются в папку `results/`.
